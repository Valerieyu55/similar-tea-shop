# 比例手搖飲經營遊戲（相似形）

康軒九上 第一章「相似形」像素風手搖飲店經營遊戲。五個區域依序解鎖，約 20 分鐘玩完：

1. 研發部：1-1 連比例
2. 杯身設計室：1-2 比例線段
3. 品牌部：1-3 相似多邊形
4. 吧台：1-4 相似三角形
5. 財務室（終章）：面積比＝相似比²

- `index.html`：遊戲本體（GitHub Pages 直接開啟）。開頭的 `LOG_URL` 填入 Apps Script 網址後，作答紀錄與排行榜才會連到 Google 試算表。
- `Code.gs`：Google Apps Script 後台（學生紀錄、排行榜、教師後台）。安裝步驟寫在檔案開頭。

設計：余佳霖老師 ・ Valerie Yu Studio ・ Find the value of you!

## 遊戲功能（2026-10 更新）
- 登入時選擇難易度：**基礎班**（數字整齊、提示免費）或 **挑戰班**（數字更刁鑽、要多一步，看提示要用提示券；排行榜分數 ×1.3）。兩種難度題號相同，後台與排行榜會標示難度。
- 終章定價改為先計算：05-4 最低售價、05-5 最高售價，再於 05-6 自行輸入大杯定價（不能用拖曳試出答案）。
- 營收用途：「店長採購單」可買店面裝潢（部分會增加客人或每杯收入）與提示券。
- 員工手冊：各區重點收錄成手冊，答題時可隨時翻閱。
- 教師後台「關卡題庫」可選基礎／挑戰版本，直接跳到任一題試玩（不記錄）。
